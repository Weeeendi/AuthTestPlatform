## 简介
使用该软件可以对 Vbox 等 Iot 设备进行授权和产测协议


> **注意**
> 设备的授权和测试功能需要设备支持，请先确认设备是否支持，是否已经集成了测试协议.

## 导出数据
该工具支持导出数据，导出数据时，先选定导出的日期和对应的pid，会自动将数据导出到本地，并生成一个压缩包，压缩包中包含所有数据，包括设备信息、测试结果、测试日志等。

> **提示**
该工具支持的操作系统为：windows10以上
